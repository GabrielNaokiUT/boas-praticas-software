## 📝 Questões:

### 1. Qual era o principal problema do código original?
O código original não cumpria com as boas práticas de desenvolvimento de software, não era auto-comentado e utilizava nomes pouco claros para as variáveis.

### 2. Quais melhorias você realizou?
- Apliquei as boas práticas de desenvolvimento de software;
- Refatorei o código separando a lógica em novos métodos(calcularMediaFinal, verificarSituacao, exibirResultado) como se fossem módulos;
- Deixei o código auto-comentado, com nomes de variáveis e métodos autoexplicativos.

### 3. Como a modularização facilitou a organização do código?
A modularização permitiu tirar toda a lógica do sistema de dentro do método main e separá-la, através dos módulos, em métodos diferentes, onde cada um realizava apenas uma função, permitindo a reutilização e facilitando o entendimento.

### 4. Como o Git ajudou a controlar as alterações realizadas no sistema?
O Git permitiu “subir” o código original para o repositório garantindo o acesso ao código-fonte, que é um dos ICs, além de registrar as alterações implementadas, permitindo a rastreabilidade do sistema, fazendo com que os outros integrantes do projeto tenham acesso histórico do ciclo de desenvolvimento do sistema.

### 📌 Sobre o Sistema e a Atividade
- **Objetivo do Sistema:** Um programa simples em Java que calcula a média final de um aluno, verifica sua situação acadêmica (Aprovado ou Reprovado) e exibe os resultados no console.
- **Objetivo da Atividade:** Aplicar boas práticas de desenvolvimento (*Clean Code*, modularização em métodos e código auto-comentado) na refatoração de um código legível, além de praticar o fluxo de versionamento no Git (criação de *branches*, *commits*, *Pull Request* e *Merge*).
  
### 🛠️ Tecnologias Utilizadas

- **Ferramenta de Versionamento:** Git
- **Plataforma de Hospedagem:** GitHub
